# enveil

流式信封加解密库（Go，仅标准库）。上层直接以函数调用，密文自包含，
可存入本地文件或经任意字节流传输；换一个进程，凭同一主密钥与业务
上下文即可解密。

## 能力

- `Encrypt(dst, src, masterKey, context, opts...)`：流式加密。
- `Decrypt(dst, src, masterKey, context, opts...)`：先验证完整性与
  真实性，通过后才交付明文；任何失败时 `dst` 收到的明文字节数为零。

主密钥固定 32 字节（256 位），可反复使用；业务上下文不参与明文、
不写入密文，但混入 HKDF info，更换上下文即解密失败。相同明文重复
加密必然产生不同密文（每份密文使用随机 salt，信封模式另有随机
数据密钥与随机包裹 nonce）。

## 密文格式

```
header:
  "ENV1"            4 字节魔数
  mode              1 字节（0=直接，1=信封）
  salt             16 字节随机（HKDF salt 兼块 nonce 前缀）
  -- 仅信封模式 --
  wrapNonce        12 字节
  wrappedKey       48 字节（32 字节数据密钥 + 16 字节 GCM tag）

body: 若干 chunk 记录
  uint32 length     大端，= 1 + 密文长度
  byte   flags      0x00 普通，0x01 最终块
  bytes  ciphertext 明文 + 16 字节 GCM tag
```

- 明文 ≤ 4096 字节：内容密钥 = HKDF-SHA256(主密钥, salt, "direct"‖上下文)，
  直接用主密钥派生密钥加密。
- 明文 > 4096 字节：随机 256 位数据密钥加密正文；KEK =
  HKDF-SHA256(主密钥, salt, "kek"‖上下文)，数据密钥经 AES-256-GCM
  包裹后存入头部。数据密钥从不以明文落盘。
- 每块 nonce = salt[0:4] ‖ 大端 64 位块序号；每块 AD = 完整头部 ‖ flags。
  因此：模式、salt、被包裹的数据密钥均受认证；块不可删除、复制、
  重排或跨密文拼接；最终块标志受认证，截断与追加都会被拒绝。
  AEAD 为 AES-256-GCM，认证强度 128 位。

## 解密的两段式保证

第一段：从源流读入全部 chunk，逐块验证 AEAD 与最终块语义，同时把
**密文**暂存到临时文件（`WithTempDir` 可指定目录，默认系统临时目录；
文件权限 0600，验证结束即删除）。源流读取失败、认证失败、结构
不完整时直接返回错误，调用方不会收到任何明文。

第二段：输入被确认完整且合法后，从暂存文件重放密文、解密并写出
明文。暂存文件只含密文，绝不含明文或未包裹的数据密钥。

工作内存与数据长度无关：逐块处理（块 1 MiB），实测 2 GiB 数据加解密
峰值额外内存约 2–5 MiB（见下方资源测试），远低于 32 MiB 上限。

## 运行测试

```sh
# 快速测试（边界、篡改、拼接、跨进程、失败路径）
go test ./...

# 完整测试：含 2 GiB 完整性与资源测试（约 30 秒，需约 7 GiB 临时磁盘）
ENVEIL_BIG=1 go test -v -timeout 20m ./...
```

注意：本机 homebrew Go 的构建缓存若损坏，可能出现
`package crypto/hkdf is not in std` 之类的错误；指定一个干净的
缓存目录即可：`export GOCACHE=/private/tmp/gocache-enveil`。

## 测试覆盖

- 空明文及 4095 / 4096 / 4097 字节边界，多 chunk 大输入；输入分批
  大小变化不影响结果；相同明文重复加密密文不同。
- 跨独立进程（子进程重 exec）解密，逐字节还原。
- 篡改：截断、追加、任意位置比特翻转、模式字节、被包裹数据密钥、
  错误主密钥、错误/空上下文；同密钥同上下文两份密文之间的头部/块
  拼接、块重排、删除、复制、伪造最终块——全部拒绝且输出目标收到
  零字节明文。
- 源流中途读取失败：零明文输出；临时文件在成功与失败路径均被清理；
  解密进行中扫描暂存文件，确认不含明文。
- 2 GiB：不可回退输入下往返逐字节一致；加解密峰值额外内存
  ≤ 32 MiB（以子进程 ru_maxrss 对比基线度量）；末尾 1 字节损坏时
  拒绝且零明文输出；临时文件不承载明文。
